# Hey, I'm Megha 👋

### DevOps / Platform Engineer

I build and run infrastructure that needs to stay **reliable, observable, secure, and reasonably cheap to operate**.

Most of my work sits around **AWS, Kubernetes, Terraform, GitOps, production troubleshooting, and platform engineering**.

---

## 🔧 What I work on

* ☸️ Building and operating production **Kubernetes / EKS** platforms
* 🏗️ Infrastructure as Code with **Terraform, Terragrunt & Ansible**
* 🚀 CI/CD and GitOps with **ArgoCD, GitHub Actions, GitLab CI & Jenkins**
* 📊 Observability with **Prometheus, Grafana & Loki**
* 🌐 Cloud and edge infrastructure with **AWS & Cloudflare**
* 🔐 Kubernetes access control, **RBAC, SSO & EKS Access Entries**
* ⚡ Production troubleshooting across **compute, networking, storage & databases**
* ⛓️ Running **blockchain nodes and indexers**
* 💰 Infrastructure right-sizing and cloud cost optimization

---

## 📌 Some things I've built / operated

* Experienced in running **multiple EKS clusters with ~80–100 worker nodes**
* Deployed and maintained **10+ blockchain nodes and Node.js indexers** across BTC, ETH, XRP, DOT and other networks
* Designed Kubernetes access models for developers across dev → production
* Improved reliability by closely tracking API latency, errors, timeouts and infrastructure health
* Automated away toil like weekly reports, infrastructure reliability reports etc.
* Written incident runbooks to turn recurring production failures into repeatable troubleshooting paths
* Set up SSO, RBAC, cluster autoscaling, cert-manager and ingress for production Kubernetes environments
* Automated deployments and rollbacks across RHEL fleets using Ansible
* Built CI/CD workflows using Jenkins, GitHub Actions, GitLab CI, Helm and Kustomize
* Built a dockerized AWS ECS/Fargate test platform that cut execution time **from 24+ hours to 1.5 hours**
* Diagnosed production issues across Kubernetes networking, databases, Kafka, storage, scaling and blockchain infrastructure
